# 第二次歸回──信仰的重建

少年班第二學年第一季第七課的互動上課網頁（以斯拉記 7–10 章）。

線上觀看：https://eric3960.github.io/ezra-second-return/

## 內容
- 前情提要：三次歸回與波斯王時間軸
- 以斯拉角色卡、拉七 10 四步驟
- 王的諭旨、出發的難題（選擇題）
- 旅程地圖：從巴比倫到耶路撒冷的路線動畫
- 信仰復興：故事排序
- 背誦經句拼句、總複習測驗、小隊計分

## 使用方式
直接用瀏覽器打開 `index.html` 即可，不需要安裝任何東西。
- 鍵盤 ← → 翻頁，F 鍵全螢幕
- 右上角「老師小抄」顯示教學參考

地圖資料來自 [Natural Earth](https://www.naturalearthdata.com/)（公有領域）。
